# Pixel Tuner · 净像

**一个 HTML 文件，离线完成图片调校。**

[在线体验](https://pixel-tuner.hurongliang.workers.dev/) · [English](README.md)

Pixel Tuner（净像）是一个在本机运行的轻量图片调校工具，支持实时调整亮度、对比度和锐度。可以在线体验，也可以下载 HTML 后在浏览器打开，选择图片即可使用，无需上传图片。

无需安装、无需后台、无统计、无外部运行依赖。

> 右上角提供 English / 中文组合切换按钮，切换无需刷新，也不会清除图片或参数。浏览器允许时会记住语言选择；首次使用默认显示英文，不跟随浏览器语言。

## 快速开始

### 在线使用

打开 **[在线体验页面](https://pixel-tuner.hurongliang.workers.dev/)** 即可开始调校。与下载版一样，图片处理在本机浏览器中完成。

### 离线使用

1. 下载 [index.html](index.html)。在 GitHub 文件页面点击 **Download raw file**，保存实际的 HTML 文件。
2. 双击文件，用较新的桌面浏览器打开。
3. 选择图片，或将图片拖入预览区。三个参数默认均为 **0%**，界面直接显示原图。
4. 拖动滑杆，或选择预设，预览会自动更新。
5. 等待原尺寸结果生成后，点击 **下载 PNG**。

点击 **重置**，参数全部归零，并立即恢复原图显示。

下载 HTML 后即可断网使用，不需要本地服务器或构建步骤。

## 功能

- **双语界面**：一键切换英文和中文，按钮、预设、状态、提示与预览弹窗同步翻译。
- **实时调校**：亮度、对比度、锐度，精度为 1%。
- **单一预览区**：参数为零时显示原图，调整时显示处理效果。
- **内置预设**：一键应用参数组合，之后仍可手动微调。
- **缩放与拖动**：点击图片打开大图预览，滚轮缩放，按住鼠标拖动查看细节。
- **原尺寸 PNG 导出**：导出图片保持解码后的原始尺寸。
- **后台计算**：像素运算在内置 Web Worker 中执行。
- **本地恢复**：尝试将原图、最近结果和参数保存在 IndexedDB。
- **单文件交付**：HTML、CSS、处理算法和工作线程代码全部内置。

## 参数说明

| 参数 | 范围 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 亮度 | −100% 至 +100% | 0% | 增加或减少像素的亮度偏移。 |
| 对比度 | −100% 至 +100% | 0% | 在亮度偏移后，围绕中间值拉伸或压缩像素值。 |
| 锐度 | 0% 至 100% | 0% | 通过反锐化掩模的近似实现增强局部细节。 |

每次调节都从原始图片重新计算，不会将上一次处理结果反复叠加。

## 参数预设

| 预设 | 亮度 | 对比度 | 锐度 |
| --- | --- | --- | --- |
| 原图 | 0% | 0% | 0% |
| 移除淘宝水印 | −10% | 20% | 20% |
| 转扫描件 | 0% | 100% | 100% |
| 移除灰色水印 | 20% | 100% | 100% |

菜单固定为四个均可选择的选项，默认选择 **原图**。选择“原图”或点击“重置”会将参数归零并立即显示原始图片。预设应用后可继续拖动滑杆微调；参数不再精确匹配时，菜单保留最近应用的预设，表示本次调校的起点。

这些预设是通用图片调校参数组合。“移除淘宝水印”和“移除灰色水印”不检测或定向移除水印，也不保证移除效果；“转扫描件”不包含 OCR、页面识别或透视矫正。

## 图片支持

| 项目 | 支持情况 |
| --- | --- |
| 输入格式 | PNG、JPEG、WebP、BMP、静态 GIF |
| 输出格式 | PNG |
| 文件大小上限 | 10 MiB（10 × 1024 × 1024 字节） |
| 解码后像素上限 | 3000 万像素 |
| 不支持的输入 | HEIC/HEIF、TIFF、SVG、APNG、动态 WebP、动态 GIF |

应用会在解码前检查文件内容，拒绝检测到的动图与不支持的格式。最终能否解码取决于浏览器。

## 实时处理方式

拖动参数时，使用最长边不超过 **1280 像素**的预览图快速显示效果。连续输入会合并，不会让大量过时任务排队。

停止调整 **250 毫秒**后，开始生成原尺寸图片；再次调整时，取消过时的原尺寸计算。只有与当前参数匹配的原尺寸结果就绪后，下载按钮才会启用。大图处理时间取决于设备性能。

参数全部为零时，预览直接显示原图。下载仍会通过 Canvas 导出 PNG，因此不是对原文件的逐字节复制。

## 隐私与离线使用

- 图片在本机浏览器中处理，不上传图片，也不发送统计信息。
- 不使用 CDN 脚本、外部字体或远程处理服务。
- HTML 内置的内容安全策略禁止应用发起网络连接。
- 图片和参数可能通过 **IndexedDB** 保存在本机；如需删除这些缓存副本，请清理对应的浏览器存储。
- 不同浏览器对本地文件缓存的支持不同。移动 HTML 文件、更换浏览器、使用隐私模式或清理浏览器数据后，可能无法恢复工作区。

请保留原始图片，并在关闭页面前下载重要结果。

## 处理效果与限制

- 高对比度可能损失照片层次，并明显改变颜色。
- 对比度为 **100%** 时，每个 RGB 通道分别变为 0 或 255，最多产生八种 RGB 颜色，并非只输出灰度或黑白。
- 锐化算法为 JavaScript 近似实现，不保证与 Pillow 或 Microsoft Word 逐像素一致。
- 浏览器解码、Canvas 颜色转换和取整可能影响像素及透明度。PNG 导出不会保留原图的 EXIF 等元数据。
- 某些设备处理大图时可能超出内存限制，失败时可尝试较小的图片。

## 开发

离线版源码为 [index.html](index.html)。直接编辑文件，再重新打开或刷新浏览器即可，无需构建。

使用 Node.js 运行逻辑测试：

```bash
node tests/test.cjs
```

测试覆盖预设菜单标签及参数应用、双语文案覆盖与语言选择、零默认值、重置、连续输入合并、过时任务取消、原尺寸导出调度与旧结果拦截，不替代真实浏览器兼容性测试。
